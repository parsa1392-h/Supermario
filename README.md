# 🍄 Super Mario Clone

A classic 2D platformer inspired by Super Mario Bros, built with Python and Pygame.

## 🎮 Features
- Smooth player movement
- Jumping and gravity system
- Enemy AI
- Collectible coins
- Classic platform gameplay
- Pixel-art graphics
- Sound effects and background music

## 🕹️ Controls
- **← / →** Move
- **Space** Jump
- **Esc** Exit

## 🚀 Installation

```bash
git clone https://github.com/your-username/super-mario.git
cd super-mario
pip install -r requirements.txt
python main.py
```
